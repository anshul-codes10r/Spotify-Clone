Spotify Clone

A Spotify-inspired music player interface built using HTML, CSS, and JavaScript.

About the Project

This is a personal frontend development project created to practise web development and build a music player with a Spotify-inspired design.

The project was developed on a mobile phone using a mobile code editor.

Features

- Home page with playlist cards and music sections
- Search page UI
- Your Library page UI
- Premium page UI
- Bottom navigation interface
- Jump Back In music section with working playback for the currently included tracks
- Responsive styling for mobile screens

Current Status

The Jump Back In section is currently the only functional music playback section. The other pages and sections are primarily UI implementations; their interfaces should not be assumed to have fully functional features.

Currently, the project includes 4 songs. Since the project was developed on a mobile phone, uploading and organizing the complete set of local assets on GitHub has been challenging. For now, only four tracks are included in the project.

The project is still a work in progress, and additional functionality may be added in future updates.

Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
